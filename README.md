# Quiz Generator App

This is a Flask web application that generates multiple-choice quizzes using OpenAI's ChatGPT API. Users can input a topic, select difficulty, and paste relevant text to generate a quiz. Each question has a timer, and results are shown with feedback and suggestions.

## Features
- Topic and difficulty selection
- Quiz questions generated by ChatGPT
- 10-second timer for each question
- Structured result summary and suggestions

## Setup Instructions

1. **Clone the repository**
   ```
   git clone https://github.com/abhinavmanoj05/quiz.git
   cd quiz
   ```

2. **Install dependencies**
   ```
   pip install -r requirements.txt
   ```

3. **Create a `.env` file** in the project root:
   ```
   API_KEY=sk-...your_openai_key...
   SECRET_KEY=any_random_secret
   ```
   - Get your OpenAI API key from https://platform.openai.com/api-keys

4. **Run the app**
   ```
   python app.py
   ```
   The app will be available at http://localhost:5050

## File Structure
- `app.py` - Main Flask application
- `templates/` - HTML templates
- `static/` - CSS files
- `.env` - Environment variables (not committed)
- `requirements.txt` - Python dependencies

## Usage
1. Enter a topic, select difficulty, and paste text.
2. Click "Generate Quiz".
3. Answer each question within 10 seconds.
4. View your score and feedback at the end.
